## Mes 2 domaines préférés

### Domaine 1 : Graphisme

- Expérience : Oui. Je dessine depuis plusieurs années et j'ai déjà réalisé différents projets graphiques dans le cadre de mes cours. J'ai également appris à utiliser Photoshop sa va faire plus d´un ans.
- Logiciels et outils : Je connais Photoshop et j'aimerais approfondir mes connaissances sur Figma.
- Pourquoi il m'intéresse : J'aime le graphisme parce qu'il me permet d'exprimer ma créativité à travers les images, les couleurs, les formes et les typographies. J'aime particulièrement le fait de pouvoir transformer une idée en une composition visuelle.
- Travailler dans ce domaine : Non

### Domaine 2 : Jeux-vidéo

- Expérience : Non, je n'ai pas encore d'expérience dans la création de jeux vidéo. Pour m'initier, j'aimerais commencer par réaliser de petits projets personnels et apprendre les bases du design d'interfaces pour les jeux.
- Logiciels et outils : J'aimerais apprendre à utiliser Unity.
- Pourquoi il m'intéresse : La conception artistique, la création de personnages et d´un univers. 
- Travailler dans ce domaine : Oui
